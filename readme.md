## Bank Account

Practicing **OOP** principles with a simple bank account class using encapsulation.

This project is an exercise created during the **Avanade Bootcamp: Back-End .NET + AI**, focusing on **Object-Oriented Programming** and the concept of **encapsulation**.

### Objective

The goal is to implement a simple `BankAccount` class with:

- **Account Number (public)** → accessible by anyone.
- **Balance (private)** → hidden and accessible only within the class.
- **Withdraw method (public)** → validates and executes withdrawals safely.

### Validation

- ✅ Encapsulation applied
- ✅ Public and private attributes
- ✅ Input validation (positive values only)
